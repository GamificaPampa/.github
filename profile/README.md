# GamificaPampa

Gamificação e IA para professores da Educação Básica. O GamificaPampa reúne projetos de extensão da UNIPAMPA, Campus Alegrete, em parceria com escolas públicas de Alegrete/RS.

Site: [gamificapampa.github.io](https://gamificapampa.github.io)

## Projetos

| Projeto      | Tema                                                                   | Coordenação                       |
| ------------ | ---------------------------------------------------------------------- | --------------------------------- |
| Educador 5.0 | Capacitação de professores para o uso de IA na Educação Básica         | Prof. Silvio Ereno Quincozes      |
| GamificaEdu  | Formação continuada em gamificação para professores da Educação Básica | Prof. Paulo Silas Severo de Souza |
